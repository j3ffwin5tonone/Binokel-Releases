# Binokel Classic – Downloads

Schwäbisches Dreier-Binokel gegen zwei Computerspieler für Windows, macOS und Linux.
Website: https://binokel-classic.de

Die Installationspakete liegen unter [Releases](../../releases):

- **Windows 10/11 (x64):** `…_windows-x64.setup.exe` (empfohlen) oder `.msi`
- **macOS 15+ (Apple Silicon und Intel):** `…_macos-universal.zip` entpacken, die App in
  *Programme* ziehen. Developer-ID-signiert und notarisiert.
- **Linux (x64):** `.deb` (Debian, Ubuntu) oder `.rpm` (Fedora, openSUSE)

Windows und macOS aktualisieren sich danach über „Programm-Updates“ in der App; jedes Paket
ist signiert, die App prüft Signatur und Version vor der Installation. `SHA256SUMS.txt` enthält
die Prüfsummen, `LIZENZEN-DRITTER.txt` die Lizenzhinweise der verwendeten Bibliotheken.

Dieses Repository enthält nur die Pakete, nicht den Quelltext.
